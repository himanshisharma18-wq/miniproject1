# 📖 Overview

A responsive **Tic Tac Toe** web application developed using **HTML5**, **CSS3**, and **Vanilla JavaScript**. The game allows two players to compete in real time on the same device while demonstrating fundamental front-end development concepts such as DOM manipulation, event handling, game state management, and responsive UI design.
